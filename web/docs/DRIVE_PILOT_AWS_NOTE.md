# Corrección para la prueba AWS

La guía `DRIVE_PILOT_SETUP.md` describe la conexión definitiva. Para la **prueba actual**, configura temporalmente `GOOGLE_DRIVE_ROOT_FOLDER_ID` con el identificador de la carpeta `AWS`, no el de `100_BIBLIOTECA_DE_CURSOS`.

Así el resultado mostrará directamente los elementos de AWS y podrás compararlos con tus 42 archivos de contenido locales. Cuando la prueba esté validada, cambiaremos esa variable al identificador de `100_BIBLIOTECA_DE_CURSOS` para la sincronización completa.
