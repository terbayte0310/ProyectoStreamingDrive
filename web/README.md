# Aplicación web de Nébula

La guía completa de instalación, Supabase, Google OAuth, Drive, migraciones y ejecución está en el [README principal](../README.md). Para la operación diaria de la biblioteca HLS y el futuro despliegue, consulta [docs/OPERACION_Y_DESPLIEGUE.md](docs/OPERACION_Y_DESPLIEGUE.md).

Inicio rápido desde esta carpeta:

```powershell
npm ci
Copy-Item .env.local.example .env.local
npm run dev
```

No confirmes `web/.env.local` ni credenciales en Git.
