# Aplicación web de Nébula

La guía completa de instalación, Supabase, Google OAuth, Drive, migraciones y ejecución está en el [README principal](../README.md).

Inicio rápido desde esta carpeta:

```powershell
npm ci
Copy-Item .env.local.example .env.local
npm run dev
```

No confirmes `web/.env.local` ni credenciales en Git.
